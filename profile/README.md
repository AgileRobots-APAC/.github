### 🚀 About Agile Robots APAC

---

Agile Robots APAC provides open software and developer resources for Agile Robots hardware in the Asia-Pacific region. From ROS 2 drivers and robot models to SDKs, examples and documentation, we help developers bring Diana robots into simulation and real-world applications quickly.

### 🧭 Getting Started

---

1. Read the [development manual](https://github.com/AgileRobots-APAC/diana_development_manual) to set up your robot and development environment.
2. Pick your integration path: **ROS 2** ([Humble](https://github.com/AgileRobots-APAC/diana_ros2/tree/humble) / [Jazzy](https://github.com/AgileRobots-APAC/diana_ros2/tree/jazzy)) or the **SDK** ([C++](https://github.com/AgileRobots-APAC/diana_sdk_cpp) / [Python](https://github.com/AgileRobots-APAC/diana_sdk_python)).
3. Run the [examples](https://github.com/AgileRobots-APAC/diana_examples_cpp) to verify your setup, then build your own application.
